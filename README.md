# إنجليزي بالراحة

صفحة ويب واحدة (`index.html`) فيها كل مميزات التطبيق، وبتشتغل على أي استضافة عادية من غير تسجيل دخول على Claude.

## تفتحها إزاي
- **على GitHub Pages:** من Settings ← Pages ← Source: `Deploy from a branch` ← اختار الفرع وفولدر `/ (root)`. اللينك هيبقى زي: `https://<username>.github.io/English/`
- **على الجهاز:** افتح `index.html` في المتصفح على طول (اللعب أونلاين والمدرس الذكي محتاجين إنترنت).

## المميزات
- كل الدروس، والنطق، والمراجعة، والإنجازات، والألعاب على نفس الموبايل — من غير نت (الأصوات جوه الملف).
- **العب مع العيلة أونلاين (كل واحد على موبايله):** غرف بكود من ٤ أرقام، بتشتغل بين الأجهزة مباشرة (WebRTC عن طريق PeerJS). لو صاحب الغرفة خرج، الباقيين بيكمّلوا لوحدهم.
- **المدرس الصبور (الذكاء الاصطناعي):** محتاج مفتاح Claude API من [console.anthropic.com](https://console.anthropic.com) — حطّه في الإعدادات ⚙️. المفتاح بيتحفظ على الجهاز بس وبيروح لـ Anthropic مباشرة.
- **تذكير يومي:** بينزّل ملف `.ics` تضيفه للتقويم.
- التقدّم بيتحفظ في المتصفح (localStorage) على كل جهاز.
